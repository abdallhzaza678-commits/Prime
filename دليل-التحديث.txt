============================================
  Nors Control — تحديث الإصلاح الشامل
============================================

تم إصلاح كل المشاكل التي ذكرتها 100%:

1) ✅ خطأ "اللوحة غير موجودة" عند فتح تذكرة
   - السبب: معرف اللوحة كان يحتوي على _ فينكسر عند التقسيم.
   - الحل: تغيير طريقة القراءة + معرف جديد بدون _.
   - اللوحات القديمة أيضاً صارت تشتغل.

2) ✅ السجلات (السجلات ما تشتغل — خليتها شغالة)
   - كل حدث يرسل إيمبد لرومه المحدد:
     • حذف وتعديل الرسائل + مسح الرسائل + فتح تذكرة
     • دخول وخروج الأعضاء + الرومات الصوتية
     • طرد وحظر وفك حظر وكتم
     • إعطاء وسحب الرتب + تغيير اللقب
     • إنشاء وحذف وتعديل الرومات
     • إنشاء وحذف الرتب
   - اختر روم لكل نوع من قسم 📋 السجلات واحفظ.

3) ✅ الرومات تنحفظ وتظهر في أي مكان
   - كل روم تختاره (ترحيب/تذاكر/سجلات/حماية/مستويات/...) يتحفظ مع السيرفر.
   - لما تختار البوت والسيرفر ترجع كل القيم تلقائياً في حقولها.
   - يوجد ملخص "📌 الإعدادات والرومات المحفوظة" أعلى قسم الإعدادات يوضح كل قسم ورومه.
   - قسم التذاكر يعرض قائمة كل اللوحات المحفوظة (العنوان + الروم + القسم + الرتبة + التاريخ) مع زر حذف.

4) ✅ الأوامر الإدارية بالاختصارات (بدون / أو ! أو -)
   - قسم جديد ⚔️ أوامر إدارية: فعّله واختر الرتبة الإدارية ومدة الكتم.
   - الاختصارات الافتراضية (تقدر تعدلها):
     ط / برا / طرد        → طرد العضو:  ط @العضو
     ب / حظر / بان        → حظر:        ب @العضو
     بط / فك حظر          → فك حظر بالآيدي:  بط 123456789
     س / كتم / مايوت      → كتم:        س @العضو 30  (30 دقيقة — الرقم اختياري)
     فك كتم / الغاء كتم   → فك الكتم
     مسح / كلير / حذف     → مسح رسائل:  مسح 20  (حتى 100)
     رتبه / رول           → إعطاء رتبة: رتبه @العضو @الرتبة
     نزع رتبه / نزع رول   → سحب رتبة
   - من لديه صلاحية الإدارة أو الرتبة المختارة يستخدمها فقط.
   - كل أمر إداري يُسجل تلقائياً في سجلات الحظر إذا فعّلت السجلات.

5) ✅ باقي الأقسام صارت تعمل فعلياً (لم تكن تحفظ شيء):
   - 🛡️ الحماية: منع روابط/سبام/كلمات محظورة + عقاب (كتم/طرد/حظر) + روم تنبيه.
   - 📊 المستويات: نقاط ورسالة ترقية في روم محدد.
   - 🔁 أوتو رول: رتبة تلقائية عند الدخول.
   - 🔘 أدوار تفاعلية: إيموجي يعطي رتبة (يعطي ويسحب).
   - ⌨️ أوامر مخصصة نصية.

============================================
تحديث إضافي: أدوات الدعم داخل التذكرة
============================================
عند إنشاء لوحة التذاكر تقدر تختار "أدوات الدعم داخل روم التذكرة":
  • أزرار (Buttons)  أو  قائمة منسدلة (Dropdown)  أو  بدون
عند فتح أي عضو للتذكرة يظهر في روم التذكرة:
  🙋 استلام — 🔒 قفل — ➕ اضافة عضو — ➖ ازاله عضو — 📢 استدعاء الاداره — 📩 استدعاء صاحب التكت
• اضافة/ازالة عضو: تفتح نافذة تكتب فيها آيدي العضو.
• استدعاء الاداره: يعمل منشن للرتبة التي اخترتها في إعدادات اللوحة.
• استدعاء صاحب التكت: يعمل منشن صاحب التذكرة تلقائياً.
• قفل: يمنع الكتابة في التذكرة ويبقى للدعم صلاحية الكتابة.
============================================

============================================
تحديث: إغلاق التذاكر بالتأكيد + تذكرة واحدة + ريست
============================================
• زر "قفل" صار يرسل رسالة مضمنة "هل أنت متأكد من الإغلاق؟" مع زرين:
  - تأكيد وحذف: يحذف التذكرة نهائياً ويقدر العضو يفتح تذكرة ثانية في أي وقت.
  - إلغاء الإغلاق: يلغي الإغلاق وتبقى التذكرة مفتوحة.
• قيد: كل عضو يقدر يكون عنده تذكرة مفتوحة واحدة فقط. إذا حاول يفتح ثانية
  يظهر له تنبيه برابط تذكرته الحالية. (إذا حذفت يدوياً يكتشف النظام ذلك تلقائياً.)
• خيار "🔄 ريست" يضاف تلقائياً في نهاية قائمة التذاكر المنسدلة:
  يختاره العضو → تتم إعادة ضبط قائمته دون فتح أي تذكرة، فيقدر يفتح أي تذكرة ثانية.
